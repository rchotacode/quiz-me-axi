# Glossary

**Quiz**: A batch of Questions that an agent puts to a user in a single request. A Quiz has no right or wrong answers; it collects the user's decisions.

**Question**: One yes/no prompt within a Quiz, made of a short title and an optional body that gives context to help the user understand what is being asked.

**Answer**: The user's Yes or No to a single Question. Every Question must have an Answer before the Quiz can be submitted.

**Clarification**: Optional free text the user attaches to a Question to qualify or explain their Answer.

**Submission**: The moment the user presses Submit, closing the Quiz and making its Answers and Clarifications available to the agent.
